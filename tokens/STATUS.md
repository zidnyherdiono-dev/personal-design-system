## Rules while status is PROVISIONAL

1. Values in these files are **placeholders chosen for legibility of previews**, not taste.
2. No consumer (human or AI agent) may present these values as the user's design preference.
3. Visual style must stay **swappable**: components may only reference tokens, never hard-code
   palette values as identity.
4. When a design direction IS decided: update this table (status → FINAL per group, add date and
   the decision reference), and change values in `tokens.json` + `tokens.css` together.
