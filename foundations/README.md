Principles that stay valid **regardless of visual style**. They explain *how to decide*, not *what to pick*.

| Doc | Covers |
|---|---|

| [typography.md](typography.md) | Type scale, hierarchy, readability |

These docs are style-neutral on purpose: they work for minimal, maximalist, dark, light, editorial,
or playful directions. The look is chosen per project — the reasoning stays.
